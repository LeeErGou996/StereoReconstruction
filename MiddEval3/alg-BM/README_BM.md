# BM Algorithm for MiddEval3

## 概述

BM (Block Matching) 算法是一个基于块匹配的立体匹配算法，使用SAD (Sum of Absolute Differences) 作为匹配代价函数。该算法实现了以下特性：

- **预滤波**: 使用x方向导数预滤波增强图像特征
- **多线程**: 支持多线程并行计算，提高处理速度
- **唯一性检查**: 使用唯一性阈值过滤不可靠的匹配
- **自动缩放**: 对过大图像自动进行缩放处理

## 算法特点

### 核心参数
- **SAD窗口大小**: 32x32像素
- **预滤波强度**: 30
- **唯一性阈值**: 20%
- **最小视差**: 0
- **最大视差**: 由输入参数指定

### 处理流程
1. **图像预处理**: x方向导数预滤波
2. **块匹配**: 使用SAD代价函数进行立体匹配
3. **唯一性检查**: 过滤不可靠的匹配结果
4. **后处理**: 输出PFM格式视差图

## 使用方法

### 命令行接口
```bash

```

## 性能特点

### 优势
- **计算效率**: 相对简单的算法，计算速度快
- **内存友好**: 内存占用相对较低
- **并行处理**: 支持多线程加速
- **鲁棒性**: 对噪声有一定的鲁棒性

### 限制
- **精度**: 相比更复杂的算法，精度可能较低
- **纹理依赖**: 在纹理较少的区域效果较差
- **遮挡处理**: 对遮挡区域的处理能力有限

## 技术细节

### 预滤波算法
使用x方向导数预滤波增强图像边缘特征：
```cpp
grad = row_above[x+1] - row_above[x-1] + 
       2 * (row_curr[x+1] - row_curr[x-1]) + 
       row_next[x+1] - row_next[x-1]
```

### SAD匹配代价
```cpp
SAD = Σ|left_pixel - right_pixel|
```

### 唯一性检查
```cpp
if (next_best_sad > min_sad * (1 + uniqueness_threshold/100))
    accept_match();
```

## 与ADCE算法对比

| 特性 | BM | ADCE |
|------|----|----|
| 算法复杂度 | 简单 | 复杂 |
| 计算速度 | 快 | 慢 |
| 内存占用 | 低 | 高 |
| 匹配精度 | 中等 | 高 |
| 纹理依赖 | 高 | 中等 |
| 遮挡处理 | 有限 | 较好 |

## 故障排除

### 常见问题
1. **编译失败**: 检查依赖库是否正确安装
2. **内存不足**: 减小输入图像尺寸
3. **运行时间过长**: 算法会自动缩放大图像
