# Disparity Map Analysis Scripts

This directory contains Python scripts for analyzing and comparing disparity maps generated by different stereo matching algorithms.

## Files

### 1. `disparity_comparison_analysis.py`
**Complete analysis script** with comprehensive features:
- Loads all available disparity maps (ELAS, ADCE, Ground Truth)
- Creates parallel comparison plots
- Generates statistical analysis
- Saves detailed reports

### 2. `quick_disparity_comparison.py`
**Quick comparison script** for fast visualization:
- Simple one-row parallel comparison
- Focuses on key algorithms
- Fast execution

## Usage

### Quick Start (Recommended)
```bash
python quick_disparity_comparison.py
```

This will generate a single row comparison of:
- Ground Truth (PFM)
- ELAS with SGM Fill
- ELAS without Fill
- ADCE Balanced
- ADCE Original

### Full Analysis
```bash
python disparity_comparison_analysis.py
```

This will:
- Load all available disparity maps
- Print detailed statistics
- Generate parallel comparison plots
- Create statistical comparison charts
- Save results as PNG files

## Output Files

### Generated by Quick Script:
- `disparity_parallel_comparison.png` - Single row comparison

### Generated by Full Analysis:
- `disparity_comparison_parallel.png` - Parallel comparison
- `disparity_statistics_comparison.png` - Statistical charts

## Customization

### Adding New Algorithms
Edit the `files_to_compare` list in `quick_disparity_comparison.py`:

```python
files_to_compare = [
    ('Ground Truth', 'disp0.pfm'),
    ('Your Algorithm', 'your_disparity.png'),
    # ... add more
]
```

### Modifying Plot Style
Adjust the `figsize` and `dpi` parameters in the scripts:

```python
fig, axes = plt.subplots(1, n_maps, figsize=(20, 6))  # Width, Height
plt.savefig('output.png', dpi=150)  # Resolution
```

## Troubleshooting

### Common Issues

1. **File not found**: Ensure disparity files exist in the current directory
2. **Import errors**: Install required packages with pip
3. **Memory issues**: Use the quick script for large images
4. **Display issues**: Scripts save files automatically, check the output directory

### File Formats
- **PFM**: Ground truth files (binary format)
- **PNG**: Algorithm output files (8-bit grayscale)

## Notes

- Scripts automatically handle different file formats
- Invalid pixels (disparity = 0) are excluded from statistics
- All comparisons use normalized disparity values for fair visualization
- Results are saved in the current directory
